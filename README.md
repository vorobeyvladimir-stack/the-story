# TheStory (Our Story 💕)

Пиксель-артовая визуальная новелла / "love quest" на чистом HTML/CSS/JavaScript.
Собрана как Telegram Web App (подключён `telegram-web-app.js`), но открывается и
как обычная веб-страница в браузере.

## Запуск

Открыть `index.html` двойным кликом в браузере.

Либо через локальный мини-сервер (Node.js не установлен, пример на Python):

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000

## Структура проекта

Каждый экран/подсистема — отдельная пара файлов (JS + CSS). Правка одного
модуля не требует открывать файлы других: логика пазла не трогает файлы
квестовых диалогов, и наоборот.

```
TheStory/
├── index.html
├── css/
│   ├── base.css      — сброс, переменные, шрифты, .screen, .btn, HUD, notif
│   ├── title.css     — титульный экран
│   ├── map.css       — карта глав
│   ├── scene.css     — диалоговая сцена (персонажи + окно диалога)
│   ├── chat.css      — мини-игра "угадай, кто написал"
│   ├── puzzle.css     — мини-игра "собери пазл"
│   └── ending.css    — финальный экран
├── js/
│   ├── core.js        — ЯДРО: state, show/showMap, buildMap, чем завершается глава
│   ├── quest.js        — диалоговый движок квестовых глав (печатная машинка, выборы)
│   ├── chat.js          — мини-игра "угадай, кто написал"
│   ├── puzzle.js         — мини-игра "собери пазл" (на headbreaker.js + konva.min.js)
│   ├── main.js             — точка входа: запускает игру после загрузки всех модулей
│   ├── storyData.js         — СЦЕНАРИЙ: главы (BG, CHAPTERS) — правьте здесь текст и ветвление
│   ├── characters.js         — SVG/картинки персонажей (man, gala, lydia)
│   ├── audio.js                — 8-битный звук на Web Audio API (клики, фанфары, BGM)
│   └── lib/
│       ├── headbreaker.js  — сторонняя библиотека паззлов
│       └── konva.min.js    — сторонняя библиотека канваса (зависимость headbreaker)
├── assets/
│   ├── man.png            — спрайт персонажа Man
│   └── ch1_puzzle.jpg     — фото для мини-игры "пазл" главы 1
└── README.md
```

Каждый JS-файл начинается с короткого комментария-контракта: что модуль
экспортирует (какие глобальные функции/объекты) и от чего он зависит. Загляните
в первые ~10 строк файла, чтобы понять, тот ли это модуль, который вам нужен,
не читая его целиком.

## Как устроена игра

Экраны (`<div class="screen">` в `index.html`) переключаются функцией `show()`
из `core.js` через класс `.active`:

- `s-title` — титульный экран
- `s-map` — карта глав (`buildMap()` в `core.js`)
- `s-scene` — диалоговая сцена с эффектом печатной машинки и выборами (`quest.js`)
- `s-chat` — мини-игра "угадай, кто написал сообщение" (`chat.js`)
- `s-puzzle` — мини-игра "собери пазл" (`puzzle.js`)
- `s-end` — финал (`showEnding()` в `core.js`)

Общий `state` (`core.js`) хранит `currentCh`/`completed` (нужны всем модулям) и
`chatScore`/`chatTotal` (пишет `chat.js`, читает `core.js` для финального экрана).
У квестового движка своё отдельное `questState` (`lineIdx`/`typing`/`choiceWaiting`)
внутри `quest.js` — оно квестовых экранов не касается, наружу не торчит.

Когда квестовая глава заканчивается, `quest.js` вызывает `endChapter()` из
`core.js` — тот сам решает, вести ли игрока в чат-мини-игру (`chat.js`) или сразу
засчитать главу пройденной (`completeChapter()`). Так `quest.js` и `chat.js`
не знают друг о друге напрямую — оба общаются только через `core.js`.

## Как добавить/изменить главу

Откройте `js/storyData.js` и добавьте объект в массив `CHAPTERS`:

```js
{
  id:'myChapter', num:8, title:'Заголовок', ico:'✨', loc:'Локация',
  chars:['gala','lydia'],
  bg:'myBg', // ключ в объекте BG
  lines:[
    {who:'NARRATOR', text:'Текст сцены...'},
    {
      who:'GALA', text:'Реплика с выбором',
      choice:true,
      choices:[
        {text:'Вариант 1', next:'branchA'},
        {text:'Вариант 2', next:'branchB'},
      ],
    },
    {who:'GALA', text:'Только если выбрали branchA', hidden:'branchA'},
  ],
  chat:true, // включает мини-игру чата после диалога
  chatLines:[
    {who:'gala', text:'Сообщение', hidden:true, answer:'gala'},
  ],
},
```

Не забудьте добавить фон в `BG`, если используете новый ключ `bg`. Это правки
только в `storyData.js` — движок (`quest.js`/`core.js`) трогать не нужно.

## Известные особенности (на заметку)

- Прогресс пройденных глав (`state.completed`) хранится только в памяти —
  сбрасывается при перезагрузке страницы. Настройка звука (mute), в отличие
  от этого, сохраняется в `localStorage`.
- На карте глав (`buildMap()` в `js/core.js`) сейчас все главы всегда открыты
  (`unlocked = true`), хотя подпись обещает открытие по порядку.
- Игра содержит личные данные (имена, города, история отношений) — учитывайте
  это, если решите когда-нибудь опубликовать проект.
